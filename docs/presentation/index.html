Chapter 1

Problem Statement

India faces catastrophic losses from floods and landslides annually. Existing systems are fragmented, reactive, and lack real-time spatial intelligence for early warning.

₹1.8L Cr
Annual Economic Loss (India)
2,500+

⚠️ Existing Challenges

  • No unified platform integrating GIS + weather + ML for real-time prediction
  • Manual, expert-driven susceptibility mapping — not scalable nationally
  • Weather data (ERA5, IMERG) unused for physics-based dynamic modelling
  • Crop damage assessments lag weeks after disasters — no early warning
  • No automated alert pipeline for district-level risk communication
  • Siloed tools for terrain, satellite imagery, and agricultural risk analysis

🎯 Our Solution

A unified, autonomous, end-to-end Prediction Engine that fuses terrain analysis, ERA5 weather data, physics-based flood/landslide models, and satellite crop intelligence — orchestrated by a multi-agent AI pipeline running 24/7 without human intervention.

✅ Key Innovation

First system to combine TOPMODEL hydrology, Infinite-Slope Factor of Safety, SCS-CN Curve Number runoff, and AHP multi-criteria GIS layers into a single real-time automated prediction platform for India.

🔑 Why Terrain Classification?

Each terrain class gets unique AHP weights for flood and landslide susceptibility. A mountain pixel gets high w_slope; a coastal pixel gets high w_elev. This makes susceptibility maps physically realistic — not one-size-fits-all.

Chapter 6

ERA5 Weather & Rainfall Analysis Engine

Automated ingestion and processing of Copernicus ERA5 reanalysis data — providing hourly, district-level meteorological fields for dynamic risk modelling.

🌦️

ERA5 Reanalysis

ECMWF ERA5 global hourly data: rainfall, temperature, soil moisture, wind, pressure, surface runoff. Fetched via CDSAPI at 0.25° resolution resampled to 2km grid.

📊

Temporal Scrubbing

24-hour temporal scrubbing in the frontend allows users to visualise hourly rainfall evolution. Data stored per district in the weather_data PostGIS table with grid geometry.

📡

Google Earth Engine

ERA5 + IMERG tasks submitted to GEE. Exports aggregated CSVs to Google Drive. Admin dashboard polls and imports into PostGIS via the WeatherDownload module.

🔬 Antecedent Precipitation Index (API)

API = Σ(Pₙ × K^n) where K = 0.85 (Kohler & Linsley, 1951). The 10-day antecedent precipitation index computes soil saturation state before each prediction date, significantly improving dynamic risk accuracy over single-day rainfall use.

Chapter 7

Dynamic Physics-Based Risk Prediction

The crown jewel — fusing susceptibility maps, 10-day weather antecedents, LULC data, and hydrological physics into date-wise dynamic risk maps per district.

⚗️ Physics Models Referenced

TOPMODEL Beven & Kirkby (1979)

Topographic Wetness Index for predicting saturated zones and lateral subsurface flow contributing to flood triggering.

Infinite Slope Iverson (2000)

Factor of Safety model accounting for slope angle, soil cohesion, friction, root cohesion, and pore water pressure for landslide triggering.

SCS-CN TR-55 (1986)

NRCS Curve Number method for surface runoff estimation based on soil type, LULC, and antecedent moisture condition (AMC-I/II/III).

🔄 Dynamic Prediction Pipeline

1
Load Weather from PostGIS
Query target_date + 10-day antecedent window per grid cell. Compute API decay.
2
Susceptibility Raster Overlay
Reproject & resample the pre-computed susceptibility .tif to the weather grid.
3
Compute Trigger Score
SCS-CN runoff + TOPMODEL TWI + API moisture → normalized trigger intensity [0–1].
4
LULC Modifier
Land use infiltration/roughness coefficients applied as final modifier.
5
Dynamic Risk = w₁·Susc + w₂·Trigger + w₃·LULC
Flood: (0.40, 0.45, 0.15) · Landslide: (0.45, 0.40, 0.15) → 5-class risk GeoJSON output.

🔁 Parallel Execution

After DATA_READY, the Orchestrator triggers GIS Agent and Crop Agent in parallel. Only after both complete does the ML Agent start. This parallelism reduces total pipeline runtime by ~40%.

🛡️ Fault Tolerance

  • 3× exponential backoff retry per failed agent
  • Partial success — continues other regions on single-region failure
  • ML fallback — uses previous day's predictions on model divergence
  • Checkpoint resume — restarts from last agent_logs record
  • n8n Error Trigger — global catch for unhandled failures

AgriIntel v2 — Satellite Crop Intelligence

A Streamlit-based satellite crop intelligence system that classifies crops from multispectral GeoTIFF images, estimates growth stages, and forecasts yield with weather risk analysis.

🛰️ Satellite Processing Pipeline

Per-pixel crop type classification. XGBoost pre-trained on pan-India training set.
4
Sowing / Harvest Estimation
Stage durations from data_bank_ref.xlsx. Back-calculates sowing, forward-calculates harvest.
5
Yield Forecast + Weather Risk
NASA POWER API → stage-wise weather risk → XGBoost + Monte Carlo (1000 sims) yield prediction.

📊 Stage-wise Risk Innovation

  • Risk computed per crop stage (not season-wide)
  • Key_Parameter receives 2.5× weight boost per stage
  • Consistency guard: extreme stage → floor overall score
  • Duration-weighted aggregation across all stages
  • 4-level output: Low · Moderate · High · Extreme

🌟 Novel Contributions

Physics Fusion Model

TOPMODEL + Infinite-Slope FoS + SCS-CN runoff combined into a single dynamic risk score — unique in open-source geospatial tools.

Terrain-Adaptive AHP

12 separate AHP weight matrices, one per terrain class — not a global average. Coastal pixels vs mountain pixels treated fundamentally differently.

Stage-wise Crop Risk

Key_Parameter 2.5× boost + consistency guards for crop stage risk — prevents paradox of low final score with extreme individual parameters.
